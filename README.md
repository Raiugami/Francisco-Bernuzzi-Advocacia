# Francisco Bernuzzi — Advocacia e Consultoria Jurídica

Site institucional de uma página para o advogado **Francisco Bernuzzi** (cliente: Francisco Bernuzzi), com mais de 30 anos de experiência nas áreas Cível, Comercial e Criminal.

**Site publicado:** a definir (ex.: https://francisco.imaguiar.com.br/)

## Descrição
Página única com abertura animada, hero, escritório, áreas de atuação (painéis interativos), citação com destaque na rolagem, como atuamos (linha do tempo), dúvidas frequentes, contato e botão fixo de WhatsApp. Texto em conformidade com o caráter informativo exigido pela OAB.

## Tecnologias
HTML, CSS e JavaScript puros (sem build). Fontes Cormorant Garamond e Manrope (Google Fonts). Respeita `prefers-reduced-motion`.

## Contatos
Os dados de contato ficam no objeto `CONFIG` no topo de `js/main.js` (WhatsApp, e-mail, telefone, endereço, OAB). Campos vazios não aparecem no site.

## Estrutura
```
index.html
css/style.css
js/main.js
img/   logo.webp, monograma.webp, favicon.png, og.png
```
